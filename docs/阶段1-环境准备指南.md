# 阶段 1 环境准备指南（1.12.2 Forge 模组构建）

> 目标：把 `ChunkOps112` 模组骨架编译通过（`gradle build`），并跑通 `runClient` 开发环境。
> 前置结论（阶段 0 已验证）：**本地工具链已就绪**，唯一缺口是网络（ForgeGradle 依赖下载）。

## 1. 已就绪的本地环境（2026-08-31 实测）

| 组件 | 位置 | 状态 |
|---|---|---|
| JDK 8 | `C:\Gradle\jdk8`（1.8.0_202） | ✅ 可用（java/javac） |
| Gradle 4.9 | `C:\Gradle\gradle-4.9` | ✅ 可用（需设置 JAVA_HOME 与 GRADLE_USER_HOME） |
| 项目骨架 | `ChunkOps112\build.gradle`（FG2.3 + 1.12.2-14.23.5.2860 + stable_39） | ✅ 已写好 |
| 测试存档 | `E:\mc\GreedyCraft`、`E:\mc\HMCL` 下多个 1.12.2 模组存档 | ✅ |

**两个已知坑**（阶段 0 实测）：
1. 系统 `JAVA_HOME=E:\Intellij\zulu-jdk25.0.3` 已失效（目录不存在），构建时必须显式设为 JDK8；
2. Gradle 的 `GRADLE_USER_HOME` 若落在不可写目录会报 `Failed to load native library 'native-platform.dll'`——必须指向可写目录（本项目用 `E:\IDE\Intellij\ChunkOps112\.gradle-home`）。

## 2. 构建命令（网络可用时）

```bat
set JAVA_HOME=C:\Gradle\jdk8
set GRADLE_USER_HOME=E:\IDE\Intellij\ChunkOps112\.gradle-home
C:\Gradle\gradle-4.9\bin\gradle.bat build
```

首次运行需下载：ForgeGradle 2.3-SNAPSHOT 插件、forge 1.12.2-14.23.5.2860、MCP 映射（stable_39）、minecraft client/server jar。国内网络建议把 `build.gradle` 中 maven 地址换为 BMCLAPI 镜像：
`https://maven.minecraftforge.net/` → `https://bmclapi2.bangbang93.com/maven/`（build.gradle 顶部有注释说明）。

## 3. 手动下载清单（网络受限时的离线方案）

若代理不可用，可手动下载以下文件并按 Gradle 缓存结构放置（或直接解压到 `%GRADLE_USER_HOME%\caches\modules-2\files-2.1\` 对应路径，文件名带 hash 较麻烦——**推荐优先开代理**）：

| 文件 | 来源 |
|---|---|
| ForgeGradle 2.3-SNAPSHOT（pom+jar） | `maven.minecraftforge.net/net/minecraftforge/gradle/ForgeGradle/2.3-SNAPSHOT/` |
| forge 1.12.2-14.23.5.2847（userdev + universal + mdk） | `maven.minecraftforge.net/net/minecraftforge/forge/1.12.2-14.23.5.2847/` |

> **forge 版本注意（已踩坑）**：1.12.2 必须用 **14.23.5.2847**——这是最后一个发布 `forge-userdev.jar` 的构建；2854/2860 在 maven 上**没有 userdev jar**，FG2.3 的 `extractUserdev` 任务会直接 404 失败（已实测验证）。2847 与 2860 对模组二进制兼容。
| mcp 映射 stable_39 | `maven.minecraftforge.net/de/oceanlabs/mcp/mcp_stable/39/` |
| minecraft_server.1.12.2.jar / client | `libraries.minecraft.net` / `s3.amazonaws.com/Minecraft.Download/versions/1.12.2/` |
| 其余传递依赖 | `libraries.minecraft.net` 下的 1.12.2 库列表（由 FG2.3 首次运行日志列出） |

**替代方案**：用 BMCLAPI 镜像（`https://bmclapi2.bangbang93.com/`）可加速绝大部分下载，无需手动整理。

