## 0. 当前最重要的事（新会话第一任务！）

**遗留问题（已定位并修复，待实测）**：GUI 跨世界复制粘贴后，**EnderIO/Forestry 部分方块变体错位**（抗燃橡木台阶→落叶树木板、脉冲合金块→玄钢梯子、玄钢块/磁钢块→空气），其他方块正常。

**根因（2026-09-02 定案，证据链完整，勿再动摇）**：REID/JEID 环境有两套**不同的**方块编号公式：
- **真·存储表 `Block.BLOCK_STATE_IDS`**（field_176229_d，MCP 名 **BLOCK_STATE_IDS**，public static final）：JEID/REID 写盘路径 `reid$newGetDataForNBT` 直接用它（palette 项 = BLOCK_STATE_IDS.get(state)），值 = **注册表 id<<4|meta**（vanilla registerBlocks 填充公式；实测存档 stone=16、water=144、mekanism:oreblock#3=112723）
- **Forge 重定义的 `Block.getStateId(state)`** = **id + meta<<12**（与存档值不一致！实测 stone→1、water→9、forestry fence→526/4622）

旧代码 `ChunkOpsExport.storageStateId` 反射候选名 `field_176229_d/stateToId/idToState/STATE_TO_ID` 在 MCP 反混淆运行时**全部不存在**（真名是 BLOCK_STATE_IDS）→ 一直回退 `getStateId` → **id<4096 的方块全部记错**。id≥4096 恰好正确（JEID patch 了 getStateId=(id<<4)|meta，与 BLOCK_STATE_IDS 一致）。"看起来正常"是因为双重错误抵消（磁盘16=石头 → 快照错标"coal_ore#15"(其错值也是16) → 写回 16 → 游戏按 BLOCK_STATE_IDS 读回石头），只在错值空间发生碰撞的模组块（EnderIO/Forestry/quark）才串块。

**修复（本次提交）**：
1. `ChunkOpsExport.storageStateId` → **直接返回 `Block.BLOCK_STATE_IDS.get(st)`**（public 字段无需反射）
2. 诊断行增加 meta 输出（15:13 实测已确认：`storageStateId=7632 = 477<<4|0` ✓ 修复生效）
3. 复制时新增 unknown 计数警告+重建提示；**明确禁止**"读盘重存修复"方案（旧编号可能被当前表误读并写回磁盘，损坏源存档）

**重要边界（2026-09-02 二次实测定案，勿绕圈）**：**部分模组（EnderIO/Forestry/quark/玄钢类）每次启动注册表编号都不同**（同款 fence 历次 id=449→475→526→477；quark biotite_slab=5599→5330→5319；而 vanilla/mekanism/divinerpg 稳定）。自检证据：15:13 会话（新 jar）diag `getIdFromBlock=477 getStateId=477 storageStateId=7632`（=477<<4|0 ✓ 修复生效）；但源 3×3 磁盘仍是旧会话值（89592 等=旧 quark 簇）→ SnapCheck 41 处 unknown。**旧会话写入的漂移簇方块，编号不可恢复**（无旧会话快照；读盘=按当前表 getByValue 翻译，碰撞方块会被误读、非碰撞方块读成空气；若玩家靠近并自动保存会把误读内容写回磁盘损坏源区——已提醒用户勿在旧源区走动）。**正确做法：用户在当前会话重建这些方块**（稳定簇 99% 解码本来就正确，无需处理）。

**下一步（用户实测流程）**：

- REID 2.3.0 核心 mixin 证据：MixinBlockStateContainer（palette 项=field_176229_d.get(state)；读=getByValue）、MixinBlock（getStateId patch：id≥4096 → (id<<4)|meta，id<4096 → 走 Forge 原版）；refmap=《mixins.jeid.core.json》required:true 全部生效

## 1. 项目是什么

1.12.2 模组兼容区块编辑器（对标 MCA Selector）：主菜单「区块编辑器」→ MCA 式 2D 地图 GUI，支持区块删除/清空/剪裁/统计/复制粘贴（跨整合包经名称化重映射不串模组块）。
技术栈：**Minecraft 1.12.2（Forge）+ JDK8 + ForgeGradle 2.3.4 + Gradle 4.9 + stable_39**（DataVersion 1343）。

## 4. 关键事实与踩坑（务必先读）

**1.12.2 存盘格式**（实测权威）：
- chunk 根 `{Level, DataVersion:1343, ForgeDataVersion, 模组根级标签}`；Level 含 ForgeCaps——复制/移动整份携带
- region 头部 location=((起始扇区<<8)|扇区数)+时间戳表；zlib 压缩
- **JEID/REID 环境**：section = `Blocks`(压缩索引高 8 位 byte[4096]) + `Data`(索引低 4 位半字节) + `Palette int[]`(stateId) + Y + 光照；无 Add
- **非 REID**：legacy（Blocks/Add/Data，index=y*256+z*16+x，x 偶=低半字节）
- **1.13 palette+BlockStates 打包**：兼容解码存在（非主路径）

**环境**：
- JDK8=C:\Gradle\jdk8；Gradle=C:\Gradle\gradle-4.9；构建：`$env:JAVA_HOME=...;$env:GRADLE_USER_HOME=E:\IDE\Intellij\ChunkOps112\.gradle-home; C:\Gradle\gradle-4.9\bin\gradle.bat build`
- forge 1.12.2-14.23.5.2847（唯一有 userdev）；产物 build/libs/chunkops-0.1.0.jar
- **写入 E:\mc（用户存档）需 danger-full-access 权限**（沙箱 workspace-write 只允许项目目录）
- 用户存档：GreedyCraft2.4.8.1（versions\…，REID 环境）；`saves\测试`（**void 世界**！spawn 附近）、`saves\地图`（**源 3×3 区 chunk (14..16,44..46)**）、`saves\你好`（15 万 sections）

**用户环境**：MCP 反混淆（LoliASM/Cleanroom/587 模组）、OptiFine U_G5、Java 25、HMCL 版本隔离；mods 路径 versions\GreedyCraft2.4.8.1\mods
