## 4. 关键事实与踩坑（务必先读）

**1.12.2 存盘格式（实测权威结论）**
- Section = legacy 数组：`Blocks` byte[4096] + `Add` byte[2048]（高 4 位 ID，id>255 时出现）+ `Data` byte[2048]（meta 半字节）；索引 `y*256+z*16+x`；**半字节顺序 x 偶=低 4 位**（NibbleArray 语义）
- **Palette+BlockStates 仅内存/网络，1.13 才写盘**（1.12 无存档样本出现过；读取端保留兼容——自造样本已验证解码）
- chunk 根：`{Level, DataVersion:1343, ForgeDataVersion, <模组根级标签如 cofhworld/forestry/Thaumcraft/MekanismWorldGen...>}`；Level 含 `ForgeCaps`；**复制/移动必须整份携带**
- region 头部：location 条目 = `(起始扇区<<8)|扇区数`；**第二张表是时间戳不是 size 表**；压缩全 zlib；chunk 数据 = 4B 长度 + 1B 压缩类型 + NBT
- **无复数 Heightmaps**，旧 `HeightMap`=int[256]（JEID 环境）或 byte？——**实测 JEID 环境 IntArray**；语义 = **最高非空气方块 y + 1**（HeightMapCheck 实证：70/69、71/70；个别列挖掘后过期 → 定位时从 heightMap-1 向下扫描兜底）
- `Biomes`：vanilla=byte[256]，**JEID 环境=IntArray[256]**（正常输出非工具破坏；biome ID 可>255）
- 结构方块文件：palette 名称化 `{Name,Properties}` + `ForgeDataVersion`（模组版本表）→ 跨模组集安全
- `.schematic`（Schematica）：数字 ID+meta（Materials:"Alpha"）→ 跨模组集必串

**P2 精确数据层（COPM v1，2026-09-01）**
- 采集：仅单人世界（`Minecraft.getMinecraft().getIntegratedServer() != null`）；ChunkEvent.Load（客户端 world）+ ClientTick 每 40 tick 扫描玩家周围（`getChunkProvider().getLoadedChunk`）双路径；2 个 daemon 线程
- 取色栈：`state.getMapColor(world,pos).colorValue` × `Minecraft.getMinecraft().getBlockColors().colorMultiplier(state,world,pos,0)`（tintIndex=0）→ `MapColorCache.shade` 高度明暗
- 路径：`<gameDir>/chunkops/map/<世界名(saves 下目录名,取自集成服务器 WorldServer saveHandler)>/<dim>/r.<rx>.<rz>.dat`；显示端读 `worldDir.getParentFile().getParentFile()/chunkops/map/<worldDir.getName()>/0/`
- 格式：COPM 魔数+版本+GZIP；u16 尺寸(256×256，列索引=dz*width+dx) + 双字典 + RLE(varint count + 4B ARGB + 1B 高度 + 2B 块索引 + 1B 群系索引)；空白/虚空列 blockIdx=0&&height=0&&color=0；**原子写 tmp+rename**
- 1.12.2 API 坑：`WorldClient.isChunkLoaded(int,int,boolean)` 是 **protected**（用 `getChunkProvider().getLoadedChunk`）；`World.getChunkFromChunkCoords` 在 1.12.2 不存在（用 `world.getChunk`）；`BlockColors.colorMultiplier` 需 4 参（tintIndex）

**JEID（Just Enough IDs）**
- GreedyCraft 类整合包核心（level.dat Version Name=`1.13-JEID`）；方块 ID 上限 **13313**（实测快照：jaopca:molten.zomril）；**id>4095 方块的存盘格式尚无真实样本**（SectionCodec palette 兼容路径已覆盖）

**环境/构建**
- JDK8 在 `C:\Gradle\jdk8`；Gradle 4.9 在 `C:\Gradle\gradle-4.9`；系统 JAVA_HOME 已失效
- **构建命令**：`JAVA_HOME=C:\Gradle\jdk8` + `GRADLE_USER_HOME=E:\IDE\Intellij\ChunkOps112\.gradle-home` + `C:\Gradle\gradle-4.9\bin\gradle.bat build`（已跑通）
- **forge 必须用 1.12.2-14.23.5.2847**（唯一带 forge-userdev.jar 的构建；2854/2860 无 → extractUserdev 404）
- Gradle 4.x 的 GRADLE_USER_HOME 指向不可写目录会报 native-platform.dll 失败
- libraries.minecraft.net 偶发握手重置 → 重试即可
- 沙箱：网络/权限需要 danger-full-access；PowerShell 写文件默认带 BOM（javac 会报错，用无 BOM UTF8）

**1.12.2 API 坑（MCP stable_39）**
- `Block.REGISTRY.getNameForObject(b)`（`getKey` 是 1.13+ 的名字）
- `Biome.REGISTRY` 同；`handleMouseInput`/`keyTyped` 声明 `throws IOException`
- `BufferBuilder` 在 `net.minecraft.client.renderer`（不是 vertex 子包）；`Tessellator.getBuffer()` 返回 BufferBuilder
- `BakedQuad` **没有** getU0/getV0（1.13+ 才有）
- `DynamicTexture` 像素是 **ABGR**（GL_RGBA 小端）——ARGB 直填会红蓝交换；转换 `(a<<24)|(b<<16)|(g<<8)|r`
- ResourceLocation 用 `toString()` 解析 modid（getResourceDomain 编译不过）
- 用户整合包（HMCL 版本隔离）：mods 在 `versions\GreedyCraft2.4.8.1\mods`（553 jars / 532 modids）；快照导出到 `versions\GreedyCraft2.4.8.1\registry-snapshot.json`
