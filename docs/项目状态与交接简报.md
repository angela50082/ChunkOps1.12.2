## 4. 关键事实与踩坑（务必先读）

**1.12.2 存盘格式**（实测权威）：
- chunk 根 `{Level, DataVersion:1343, ForgeDataVersion, 模组根级标签}`；Level 含 ForgeCaps——复制/移动整份携带
- region 头部 location=((起始扇区<<8)|扇区数)+时间戳表；zlib 压缩
- **JEID/REID 环境**：section = `Blocks`(压缩索引高 8 位 byte[4096]) + `Data`(索引低 4 位半字节) + `Palette int[]`(stateId) + Y + 光照；无 Add
- **非 REID**：legacy（Blocks/Add/Data，index=y*256+z*16+x，x 偶=低半字节）
- **1.13 palette+BlockStates 打包**：兼容解码存在（非主路径）

**环境**：
- JDK8=C:\Gradle\jdk8；Gradle=C:\Gradle\gradle-4.9；构建：`$env:JAVA_HOME=...;$env:GRADLE_USER_HOME=E:\IDE\Intellij\ChunkOps112\.gradle-home; C:\Gradle\gradle-4.9\bin\gradle.bat build`
- forge 1.12.2-14.23.5.2847（唯一有 userdev）；产物 build/libs/chunkops-0.1.0.jar
- **写入 E:\mc（用户存档）需 danger-full-access 权限**（沙箱 workspace-write 只允许项目目录）
