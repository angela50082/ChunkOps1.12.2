## 一、操作步骤

1. **注册/登录**：<http://www.mcmod.cn/reg>（支持 QQ 登录）。新账号是「百科用户」，可以正常提交，只是内容需要编辑员审核。
2. **进入添加模组页**：登录后点首页右侧的 `添加模组`，或直接打开 <http://www.mcmod.cn/class/add>。
3. **按下面第二节逐项填写**（编辑器一栏填第三节的简介正文）。
4. **封面上传**（选填但建议填）：
   - 用仓库里的 `docs/artwork/mcmod-cover-240x150.png`（**正好 240×150**，百科要求的尺寸）；
   - 上传方式：在编辑器里点图片按钮 → `本地上传` → 添加照片 → 上传后**单击这张图**，再点一次图片按钮，切到 `远程图片` 选项卡，就能拿到站内图片地址 → 把它粘到「封面」栏（官方要求尽量用站内地址）。
5. **提交**：点 `提交修改`（旁边可先 `预览内容`）。
   - ⚠️ **普通用户（百科用户组）提交时需要填「验证码」**：表单**最底部、`提交修改` 按钮附近**有一张图片验证码，把图里 **2 个字符**照抄进输入框即可（官方《用户组》写明「验证码长度：百科用户 2 / 编辑员 0」）。
   - 如果提示「未填写验证码」→ 点弹窗里的 `再改动` 回表单（内容不丢），按 `Ctrl+F` 搜「验证码」定位后补填再提交。
   - 如果验证码图片是空白/裂图：先关掉广告拦截类浏览器插件或换浏览器；**刷新前先把表单内容复制到记事本备份**（刷新可能清空已填内容）；成为「百科编辑员」后验证码长度为 0，就不用再填了（见第五节）。
6. **等审核**：在 <https://www.mcmod.cn/verify.html> 或你的「个人中心 → 我的编辑」里看状态。审核由编辑员/资深编辑员处理，一般几天内；被退回会写明原因，改完重交即可。
7. **收录之后**：
   - 把模组页地址（形如 `https://www.mcmod.cn/class/xxxxx.html`）补到 README 顶部与 GitHub 仓库 About；
   - 继续补充内容：本模组没有物品/方块，主战场是**教程**（见第四节）；
   - 想免审核直接编辑、或想获得「作者」标识：见第五节。

## 三、简介正文（直接复制到「编辑器」栏）

### ⚠️ 先说编辑器区别

百科的编辑器在个人中心可切换：**富文本（默认，推荐）** 与 **Markdown**。

- 用**富文本**：**Markdown 语法不会被解析**，`**加粗**`、反引号 `` ` `` 会原样显示出来（预览里能看到一堆星号）。→ 用下面 **3.1 富文本版**（已去掉所有 Markdown 符号）。
- 用 **Markdown**：才用 **3.2 Markdown 版**。

选哪一个都不影响审核，看你自己顺手；两种版本内容完全一致。

### 3.1 富文本版（默认编辑器用这个，直接整段复制）

ChunkOps 是一个运行在游戏内的区块级存档编辑器，属于客户端模组，面向单人存档（Minecraft 1.12.2 / Forge）。它不通过游戏加载世界，而是直接读取与写入存档目录下的 region 文件夹中的 mca 文件，在主菜单即可打开一张 MCA Selector 风格的 2D 地图界面，用来浏览、整理和搬运存档。

主要功能：

地图式浏览：颜色由方块地图色、生物群系调色与高度坡度明暗合成，可辨认地形与建筑轮廓；支持主世界、下界、末地与模组维度（自动扫描存档下的 DIM 目录）；浏览结果会缓存，二次打开很快。

区块操作：框选后可以移除（删除区块，让游戏重新生成）、清空（保留空区块）、剪裁（删除框选之外的全部区块）、统计（按方块名统计数量，可过滤与排序）。

跨存档与跨维度搬运建筑：复制框选区域后切换到另一个存档或维度粘贴。搬运以「方块名称 + 元数据」为单位进行重映射，因此在同一个整合包内不会串方块，并会连同方块实体（箱子、机器等）、实体、光照、生物群系与模组区块数据一起带走；粘贴前有半透明预览，可拖动定位后再确认。

安全措施：每次写入前自动生成 mcabackup 备份文件，写入后回读校验；内置只读模式，可先浏览确认再放开写入；检测到 session.lock 时会提示存档可能正被游戏占用。

适用于需要清理异常或卡地形区块、剪裁存档体积、统计区域方块构成，或把建筑在存档与维度之间搬运的场景。对使用 REID / JEID 一类会重排方块数字编号的大型整合包也做了兼容处理。

注意事项：仅支持 Minecraft 1.12.2 与单人存档；模组会直接修改存档文件，使用前请务必备份；编辑前后不要改动 mods 目录（增加、删除或替换任何模组都可能使模组方块编号重排，导致旧存档数据被错误解释）。界面支持简体中文与英文，跟随游戏语言。

**想让排版更好看（可选，20 秒）**：
1. 选中「主要功能」四个字 → 点工具栏的 **B**（加粗）；
2. 选中「地图式浏览」「区块操作」「跨存档与跨维度搬运建筑」「安全措施」这四行 → 点工具栏的**无序列表**按钮，就会变成圆点列表；
3. 想强调「不会串方块」「不要改动 mods 目录」等关键词，选中后点 **B**。

> 代码/文件名（`region`、`mods`、`session.lock`）在富文本里**不要用反引号**，要么直接写、要么用编辑器工具栏的「代码」按钮。

## 八、审核意见处理（收录后打磨）

### 8.1 官方状态被标成「停更」

百科规则：**活跃**＝状态正常、保持更新；**半弃坑**＝超过 6 个月没发更新文件；**停更**＝超过 1 年没发更新文件或明确弃坑。
我们的模组是**当天发布**的，按规则不该是停更，而页面「更新日志」是空的（`暂无日志`）——所以大概率是审核时手填的，或系统在**没有任何更新记录**时的默认值。处理顺序：

1. **先补更新日志**（模组页左侧 `新建日志`，官方文档：[日志添加/编辑教程](https://mcmod.readthedocs.io/zh/latest/log/)）。字段：编辑器（更新内容）、版本名称（与官方版本一致）、更新日期（按官方时间）。填两条：
   - ⚠️ **日志同样要审核**：官方《用户组》权限表里，百科用户的「免审核编辑」是 ×（编辑员/资深才是 √），所以日志提交后不会立刻显示，页面会先留着 `暂无日志`，别因为看不到就重复提交（会变重复条目）。
   - **提交顺序：先 0.1.0，再 0.1.1**。官方文档写明「日志非编辑员无法排序」，按时间顺序提交最保险；更新日期填 GitHub Releases 上的官方日期。
   - 版本名称 `0.1.1`，更新日期填 Releases 里 v0.1.1 的日期，内容：
     `界面文案改为语言文件，支持简体中文与英文（跟随游戏语言）；修复部分环境下界面显示为键名的问题；加入 GitHub Actions 自动构建与发版流程。`
   - 版本名称 `0.1.0`，更新日期填 v0.1.0 的日期，内容：
     `首个公开版本。MCA Selector 风格的 2D 地图浏览（主世界/下界/末地/模组维度）；区块移除、清空、剪裁与方块统计；按方块名称重映射的跨存档/跨维度复制粘贴（保留方块实体、实体、光照与生物群系）；持久地图缓存；写入前自动备份与只读模式。`
2. **再改官方状态**：模组页 `编辑模组` → `官方信息` → 官方状态选 **活跃** → 提交（普通用户要填验证码）。
3. 若仍被改回「停更”：在页面**短评/讨论区**问一句编辑员判定依据，并附 `https://github.com/angela50082/ChunkOps1.12.2/releases`（两个版本都是当天发布的）。

> 补日志不只是为了这个徽章：它同时提高「资料填充率」，也让玩家一眼看到这个模组还在维护。

### 9.1 富文本版（粘进编辑器后按提示点两下工具栏）

ChunkOps 是一个运行在游戏内的区块级存档编辑器，客户端模组，面向单人存档（Minecraft 1.12.2 / Forge）。它不加载世界，而是直接读写存档目录下的 region 文件，在主菜单即可打开一张 MCA Selector 风格的 2D 地图，用来浏览、整理与搬运存档。

【功能一览】

· 地图式浏览：颜色由方块地图色、生物群系调色与高度坡度明暗合成，可辨认地形与建筑轮廓；支持主世界、下界、末地与模组维度；浏览结果会缓存，二次打开很快。

· 区块操作：移除（删除区块，让游戏重新生成）、清空（保留空区块）、剪裁（删除框选之外的全部区块）、统计（按方块名统计数量，可过滤与排序）。

· 跨存档搬运：复制框选区域后切换到别的存档或维度粘贴；按「方块名称 + 元数据」重映射，同一整合包内不会串方块，并会连同方块实体、实体、光照、生物群系与模组区块数据一起搬运；粘贴前有半透明预览，可拖动定位后再确认。

· 安全保障：每次写入前自动生成 mcabackup 备份，写入后回读校验；内置只读模式；检测到 session.lock 会提示存档可能正被游戏占用。

· 界面语言：简体中文与英文，跟随游戏语言设置。

【使用流程】

1. 打开编辑器：主菜单的「区块编辑器」按钮，或 模组列表 → ChunkOps → 配置 → 打开区块编辑器。

2. 用顶部下拉选择存档与维度。

3. 左键拖动框选区块；中键拖动平移视图，滚轮缩放，右键取消框选。

4. 右侧工具面板执行 移除 / 清空 / 剪裁 / 统计。复制用 Ctrl+C；粘贴用 Ctrl+V（先显示半透明预览并拖动定位，再按一次 Ctrl+V 确认写入）。

【注意事项】

· 模组会直接修改存档文件，使用前请务必备份存档。

· 编辑前后不要改动 mods 目录：增删或替换任何模组都可能使模组方块编号重排，导致旧存档数据被错误解释。

· 仅支持 Minecraft 1.12.2 与单人存档。

· 地图为示意图：颜色由地图色、群系调色与高度明暗合成，用于辨认地形与建筑轮廓，不是逐方块贴图渲染。

**排版操作（在富文本编辑器里，30 秒）**：
1. 选中「【功能一览】」「【使用流程】」「【注意事项】」三行 → 点工具栏 **B** 加粗（如果想更醒目，可用工具栏的「标题」样式）；
2. 选中 5 条以 `·` 开头的行 → 点**无序列表**按钮，变成圆点列表后把行首的 `·` 删掉；
3. 选中 4 条以数字开头的行 → 点**有序列表**按钮，变成 1./2./3./4. 列表后删掉原来的数字；
4. 最后把多余的空行删掉，保持「段落之间一个空行」。
